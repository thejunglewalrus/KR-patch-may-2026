## Translation conventions

Class names use the official Western client localization, not transliterations of the KR name:

- 스카우터 &rarr; **Machinist** (not "Scouter")
- 워로드 &rarr; **Gunlancer** (not "Warlord")
- 데빌헌터 &rarr; **Deadeye**, 데모닉 &rarr; **Shadowhunter**, 블레이드 &rarr; **Deathblade**, etc.

Mode/feature names use the published Western names where known:

- 증명의 전장 &rarr; **Proving Grounds** (PvP arena &mdash; distinct from the Paradise &ldquo;Crucible&rdquo; mode)
- 낙원 천상 / 증명 / 지옥 &rarr; **Paradise Elysian / Crucible / Hell**
